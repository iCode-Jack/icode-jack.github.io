What is a .mock file?

A .mock file is an ExamMocker package containing structured exam data and associated resources used by the app.

How it works

    Get an authorized .mock file

    Obtain a .mock file from an authorized source.

  3. 2

    Open or import the file using the device workflow.

  4. ↓
  5. 3
    Open the exam

    The structured exam content loads in the app.

  6. ↓
  7. 4
    Start practicing

    Begin your mock-exam practice session.
