Getting and using .mock files

How ExamMocker packages work.

What is a .mock file?

A .mock file is an ExamMocker package containing the structured exam data and associated resources needed by the app.

How to get a .mock file

Use .mock files supplied or authorized by the developer, your school, organization, course provider, or another legitimate source.

Do not redistribute copyrighted exam materials without permission.

How to import a .mock file

  1. Obtain the .mock file.
  2. Save it to a location accessible from your device.
  3. Use the iOS Files / Share workflow to open or import the file into ExamMocker.
  4. Open the imported exam in ExamMocker.

FAQ

What if my .mock file cannot be opened?

Make sure the file is complete, keeps the .mock extension, and was created for a compatible ExamMocker version. If the problem persists, contact support and include the app version and relevant error details.

Can I rename a .mock file?

Keep the .mock extension intact and use files provided for ExamMocker.
